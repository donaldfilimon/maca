# Security Policy

## Supported versions

Only the latest commit on the `main` branch is actively supported for security updates.

## Reporting a vulnerability

If you discover a security vulnerability in maca, please **do not open a public issue**.

Instead, send a private report to the maintainer via one of:

- GitHub private security advisory (preferred when available): use the "Report a vulnerability" button on the Security tab of the repository.
- Email: see the address listed in the repository or Cargo.toml if present.

Please include as much detail as possible:
- Description of the issue
- Steps to reproduce
- Affected versions
- Potential impact

We will respond as quickly as possible and work with you to understand and address the issue.

## Scope

This policy covers the core `maca` binary and library. It does not cover:
- Packages installed *by* maca (those are the responsibility of their upstream projects)
- Third-party dependencies (report those to their respective maintainers)

Thank you for responsibly disclosing security issues.
